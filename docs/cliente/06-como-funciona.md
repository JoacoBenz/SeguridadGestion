## Paso a paso

### 1. Llega el paquete

El conserje abre PaqueteOK en el navegador de su celular, toca "Registrar", elige la unidad de una grilla y confirma. Puede agregar el transportista o una nota. En segundos el paquete queda registrado y aparece en la lista de pendientes.

### 2. El residente recibe el aviso

Automáticamente, el residente recibe un mensaje de **WhatsApp** con:

- El nombre del edificio y su unidad.
- Un **código de retiro** de seis caracteres.
- Un **código QR** como imagen del mensaje.

No tiene que instalar nada ni registrarse. Si quiere que lo retire otra persona, reenvía el mensaje: el QR y el código siguen siendo válidos.

### 3. El retiro

Cuando alguien pasa a buscar el paquete, el conserje tiene dos caminos:

- **Escanear el QR** con la cámara del celular, o
- **Tipear el código** de seis caracteres.

El sistema valida y marca el paquete como retirado. El código deja de ser válido en ese momento.

### 4. La confirmación

El residente recibe un segundo WhatsApp confirmando el retiro, con la hora exacta. Queda todo registrado en la auditoría del edificio.

## ¿Qué pasa si…?

**¿…el residente borra el mensaje?**
El código de retiro sigue siendo válido. Desde el panel se puede reenviar el aviso.

**¿…no atiende o no ve el WhatsApp?**
El paquete queda en la lista de pendientes de la conserjería, visible y ordenado por antigüedad, hasta que se retire. No se pierde.

**¿…viene un familiar o un repartidor a buscarlo?**
El residente reenvía el mensaje de WhatsApp. Quien tenga el QR o el código puede retirar.

**¿…el residente dice que "nunca le avisaron"?**
El registro muestra exactamente cuándo se envió el aviso, si se entregó y si se leyó *(seguimiento de estados disponible en el plan Completo)*.

**¿…se registró un paquete por error?**
El administrador (o el conserje, según los permisos) puede cancelarlo dejando el motivo, y la cancelación queda auditada.

**¿…el edificio tiene mucho movimiento?**
La conserjería está pensada para uso intensivo desde el celular: grilla de unidades, escaneo rápido y lista de pendientes siempre a mano.
